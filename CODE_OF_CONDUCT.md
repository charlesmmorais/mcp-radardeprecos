# Código de conduta

Este projeto adota o
[Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: participe com respeito, aceite críticas construtivas, foque no que
é melhor para a comunidade e não tolere assédio de nenhuma forma.

Comportamentos inaceitáveis podem ser relatados de forma privada ao mantenedor
pelo [relato privado do GitHub](https://github.com/charlesmmorais/mcp-radardeprecos/security/advisories/new).
Todos os relatos serão analisados com confidencialidade.
